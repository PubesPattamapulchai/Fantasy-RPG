# Emberfall — Blackstar 2D Ascendant v13

Blackstar 2D Ascendant v13 keeps Emberfall fully 2D while pushing the presentation and combat feel further toward a modern dark-fantasy action RPG.

## Gameplay upgrades
- New Combat Flow meter rewards varied actions instead of repeating the same command.
- Reaching 100 Flow primes a Flow Surge: the next damaging action gains a substantial damage and stagger bonus.
- Damage-type sequencing now creates real elemental reactions:
  - Fire + Poison: **Combustion**
  - Arcane + Radiant: **Veilflare**
  - Frost + Physical: **Shatter**
  - Other changed damage types: **Chain Reaction**
- Reactions grant additional damage, stagger and Momentum, creating more deliberate skill/weapon sequencing.
- Flow, reaction state and readiness are exposed through the presentation bridge for the modern HUD.
- Existing dodge, parry, execution, positioning, surfaces, environment actions, companion doctrines, Covenant Surges, Skill Sigils, Runestones, World Tiers, Hunt Chains, Nemesis enemies, boss phases and deep loot remain intact.

## 2D graphics and presentation
- New cinematic Canvas2D overlay for weapon trails, impact rings, spell particles, boss aura and combat flashes.
- Stronger 2D enemy telegraphs and battlefield surface lighting.
- More atmospheric world motes and biome-specific foreground grading.
- Boss phase transitions receive additional particles, aura and screen feedback.
- New elemental-reaction banners and a dedicated Flow Surge HUD meter.
- Battle controls are reorganized visually into offensive, defensive, party and utility families.
- Cleaner dark-fantasy panels, meters, enemy status treatment and responsive mobile combat layout.

## Compatibility
- The game remains fully 2D. No Three.js or WebGL 3D runtime is used.
- Save format is version 10 and migrates existing versions 3–9.
- PWA cache is `emberfall-blackstar-2d-v13`.
- Existing accessibility preferences remain supported, including reduced motion, blood FX, combat text, camera impact and screen flash options.
- No executable, installer, DLL, BAT, CMD or PowerShell payload is required.
