# Emberfall — Blackstar Reforged Edition

Blackstar Reforged pushes Emberfall toward a modern cinematic party-RPG and dark loot-driven action-RPG feel while keeping the world, artwork, names, and rules original.

## Gameplay
- Hunt Chains reward consecutive victories with scaling challenge, higher elite pressure, richer rewards, and milestone caches.
- Optional Tactical Guide reads enemy intent and highlights a useful response without playing the turn for you.
- Following a recommendation once per round earns a Tactical Read bonus and can improve battle rank.
- Companion commands can become Covenant Surges at Bond 20+ with enough Momentum, adding stronger party payoff and cinematic feedback.
- Existing World Tiers, Nemesis enemies, parries, dodges, executions, Ward, surfaces, positioning, reactions, Skill Sigils, Runestones, passive Constellation, loot affixes, and boss phases remain intact.

## Friendly UX / UI
- Dedicated Options panel for Tactical Guide, Reduced Motion, Large Text, High Contrast, and Compact HUD.
- Quick HUD shows Hunt Chain, estimated Gear Power, and guide status.
- Contextual combat coach explains why an action is useful.
- Action Inspector/tooltips explain every combat command in plain language.
- Battle actions use clearer visual categories for offense, defense, party/build tools, and consumables/environment.
- Recommended actions receive a gold focus treatment that can be disabled.
- Mobile combat uses larger two-column actions and improved focus/readability.

## Presentation
- Deeper battle-floor perspective, stronger contact shadows, restrained cinematic glow, improved boss/Nemesis emphasis, refined panels, and clearer meter depth.
- Existing pixel-art identity is preserved instead of imitating proprietary artwork.

## Compatibility
- Save format version 9 migrates versions 3–8.
- GitHub Pages and PWA/offline support remain enabled.
- No Windows executable, installer, DLL, or script payloads are introduced.
