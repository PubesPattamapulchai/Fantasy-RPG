# Emberfall — Nightfall Covenant Edition

Nightfall Covenant deepens Emberfall's modern dark-fantasy combat and buildcraft while keeping the project original.

## Gameplay
- Two-step enemy intent timeline (NOW / NEXT).
- Ward barrier that absorbs incoming damage.
- Three companion doctrines: Assault, Guardian, Support.
- Eight Skill Sigils with different build effects and rare drops.
- Broken-state vulnerability after posture/stagger breaks.
- More rewarding elite/Nemesis loot reveals.
- Skill Sigils integrate with stamina, Momentum, surfaces, companion commands, criticals, executions, and parries.
- Existing World Tiers, runestones, constellation, weapon techniques, boss phases, d20 checks, reactions, dodge/parry, and the full campaign remain intact.

## Graphics
- Deeper battle-floor perspective.
- Contact shadows and stronger character grounding.
- Cinematic lens/vignette and darker world grading.
- New intent timeline, Ward meter, loot reveal, Skill Sigil cards, and combat category styling.
- Nemesis and Phase III battles receive stronger visual treatment.

## Compatibility
- Save version 8 migrates versions 3–7.
- Static GitHub Pages / PWA deployment remains supported.
- No executable or installer files are added.
