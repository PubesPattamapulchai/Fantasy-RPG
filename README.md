# Emberfall — 8-bit Fantasy RPG

A responsive, dependency-free browser RPG built with vanilla HTML, CSS, and JavaScript.

![Emberfall preview](assets/promo.png)

## Play

Open `index.html` locally, or deploy the repository with GitHub Pages.

### Controls

- Move: Arrow keys or WASD
- Interact: Space or Enter
- Mute: M
- Touch: On-screen D-pad and action button

### Features

- Procedurally drawn pixel-art world
- NPC dialogue and a short quest
- Turn-based battles
- Treasure, potions, gold, experience, and leveling
- Local save/continue system
- Responsive touch controls
- No frameworks, packages, or build step

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `emberfall-rpg`.
2. Upload every file in this folder, including the hidden `.github` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push to the `main` branch. The included workflow publishes the game automatically.

Your game URL will be:

`https://YOUR-USERNAME.github.io/emberfall-rpg/`

## Customize

- Game rules and map: `game.js`
- Colors and layout: `styles.css`
- Page title and text: `index.html`
- Social preview: `assets/promo.png`
